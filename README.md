# My Portfolio

A simple, responsive personal portfolio website built with **HTML, CSS, and JavaScript**. This is designed as a beginner-friendly first GitHub repository.

## Features

- Responsive design for desktop and mobile
- About, skills, projects, and contact sections
- Mobile navigation menu
- Light/dark mode
- No frameworks or dependencies

## Project structure

```text
my-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Customize it

Open `index.html` and replace:

- `Your Name`
- `your.email@example.com`
- `yourusername`
- About Me text
- Skills
- Projects

You can also change the design in `style.css`.

## Publish with GitHub Pages

After creating your GitHub repository:

```bash
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/my-portfolio.git
git push -u origin main
```

Then enable **GitHub Pages** in the repository's Pages settings and select the `main` branch.
